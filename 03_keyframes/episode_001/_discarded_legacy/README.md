# Episode 001 Discarded / Legacy Keyframes

This folder preserves deprecated or misfiled episode 001 keyframe assets.

## Rule

- Do not delete generated keyframes unless explicitly requested.
- Move obsolete, misfiled, or superseded assets here so the active keyframe folders stay clean.
- Keep folder names and filenames unchanged when possible, so old logs still remain traceable.

## Current Contents

- `old_segment01_folders/`: early Segment 01 folders from the pre-progressive workflow.
- `misfiled_or_superseded/`: individual files marked as misfiled, previous local versions, or clearly superseded.

## Restoring

If an archived asset becomes useful again, copy it back to the matching active keyframe folder and record the reason in `09_logs/decision_log.md`.
