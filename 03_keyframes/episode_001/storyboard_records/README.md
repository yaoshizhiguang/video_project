# Episode 001 Storyboard Records

This folder records storyboard assets and how they should be used for video generation.

Actual storyboard images stay in:

- `03_keyframes/episode_001/storyboards/`

Records in this folder should explain:

- storyboard file path
- related segment
- source keyframes or references
- recommended upload order
- matching video prompt file
- status and notes after video tests

## Current Rule

Use one storyboard image per video generation task whenever a segment needs multiple beats. Do not upload many separate keyframes to the same video task unless the tool specifically handles them as a timeline.

The storyboard only records stages, composition, and state changes. It does not replace the video prompt. Every dynamic detail must be described in the prompt: timing, motion direction, VFX source, energy flow, cause and effect, object movement, character reaction, and forbidden mistakes.

Future video prompts should be Chinese by default unless the user asks otherwise.
