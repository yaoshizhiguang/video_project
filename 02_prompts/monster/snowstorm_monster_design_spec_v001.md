# Snowstorm Monster Design Spec v001

## 用途

用于锁定第一集暴风雪怪的设计边界。当前策略不是继续发明新怪物，而是以 `00_references/monster/images/variations/snowstorm_monster_v001_001.png` 为主参考做小幅强化。

## 核心原则

- 以 v001 为主参考，下一版只允许“小幅强化”，不要重新发明怪物。
- 惊艳来源只能来自光效、体量、蓝色内发光、冰晶漂浮和风雪氛围。
- 不能通过王冠、胡子、肌肉、尖刺、复杂表情或新身份来制造记忆点。
- Prompt 必须强调：`based on the first successful design, only refine the same snow-cloud boss`。

## 设计规格表

| 模块 | 必须保留 | 可以增强 | 必须禁止 |
| --- | --- | --- | --- |
| 整体身份 | 巨大雪云怪、暴风雪 Boss、儿童动画反派 | 更强蓝色内发光、更强风雪压迫感 | king、storm king、titan、wall、snowman |
| 轮廓 | 大、厚、圆、慢、笨重 | 上半身更宽，底部更像雪雾堆 | 人形肩膀、健身巨人、两条腿 |
| 脸 | 蓝色发光眼、云洞大嘴 | 眼神更冷一点，大嘴更清晰 | 眉毛、胡子、王冠、老人脸、笑脸 |
| 手臂 | 模糊云团侧翼 | 弱化成“侧面鼓出的雪云团” | 拳头、手掌、手指、肌肉臂 |
| 下半身 | 宽雪雾底座 | 更蓬松、更容易被雪球包住 | 龙卷风尖锥、腿、脚 |
| 冰晶 | 少量点缀 | 加几片漂浮冰晶增加吸睛度 | 冰甲、冰刺怪、皇冠 |
| 情绪 | 有威胁但不恐怖 | 像第一集危机 Boss | 恐怖怪、灾难片、最终魔王 |

## 必须避免的方向词

下一版不要再写：

```text
King / crown / beard / snowman-like / wall / natural disaster
```

应该写：

```text
based on the first successful design, only refine the same snow-cloud boss
```

## 通过标准

- 第一眼能看出是 v001 的同一个雪云怪，只是更高级。
- 角色身份仍是“雪云怪”，不是雪人王、冰巨人、灾害墙或肌肉怪。
- 画面可以更有光效和压迫感，但轮廓不能变复杂。
- 手臂必须像云团侧翼，不能像拳头或手掌。
- 最终仍能想象被雪球包成巨大雪人，但当前形态不能直接像雪人。

## 失败判定

- 出现王冠、胡子、眉毛、老人脸或笑脸：失败。
- 出现拳头、手掌、手指、健身巨人肩膀：失败。
- 变成纯灾害场景、暴风雪墙、龙卷风或抽象云团：失败。
- 变成圆滚滚雪人、圣诞雪人或吉祥物：失败。
- 通过尖刺、冰甲、武器或复杂面部表情制造“惊艳”：失败。
