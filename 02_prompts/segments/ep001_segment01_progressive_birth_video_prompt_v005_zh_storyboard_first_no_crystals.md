# Episode 001 Segment 01 Progressive Birth Video Prompt v005 - 中文故事板输入版 - 去廉价冰晶

## 用途

用于第一段 10 秒雪怪渐进生成视频：平静南极 -> 异变开始 -> 雪怪由腹部漩涡聚合 -> 半成型抬升 -> 完整现身 -> 首次攻击。

本版基于 v004 另存，不覆盖原文件。  
重点修正：

- 后续视频 prompt 默认中文。
- 视频生成不要上传多张独立关键帧，避免模型把它们理解成要拼接的视频剪辑或幻灯片。
- 多个关键阶段必须先合成一张故事板图，再上传“设定图 + 单张故事板图”。
- 故事板只作为剧情阶段和构图参考，不能指望模型从故事板自动理解动态。
- 所有运动、特效、时间轴、因果关系和转场方式必须在 prompt 中写清楚。
- 避免菱形冰晶、悬浮水晶、硬质冰片和廉价闪光碎片，把冰雪特效写成细冰粉、霜雾、半透明雪粉、柔和冰蓝光带和流体螺旋运动。

## 推荐上传顺序

1. 雪怪设定图：`00_references/monster/images/model_sheets/ep001_snowstorm_monster_model_sheet_v003_production.png`
2. 第一段雪怪生成故事板图：把 Shot A-F 的关键阶段先合成单张故事板后上传。

不要上传 Shot A、Shot B、Shot C、Shot D、Shot E、Shot F 多张独立关键帧给同一个视频任务。  
如果还没有第一段生成故事板，请先用这些关键帧合成一张故事板图，再进入视频生成。

## 一键复制 Prompt（正向内容 + Avoid 负向约束）

说明：下面是一整段可直接复制到生成工具的中文 prompt。`Avoid:` 之后是负向约束，不要删掉。

```text
@Image1 仅作为暴风雪怪物的唯一外观设定参考，严格保留雪怪的深色雪云身体、蓝色发光眼睛、云洞状大嘴、腹部中心漩涡、宽大的雪雾底座和整体比例，不要重新设计雪怪。@Image2 仅作为第一段雪怪生成过程的故事板参考，用来理解平静、异变、聚合、半成型、完整现身、首次攻击这几个剧情阶段。不要复制故事板分格、白边、编号、字幕、箭头或文字，不要把最终视频做成多格拼贴、幻灯片或连续切图。故事板只提供阶段参考，所有动态变化必须严格按照下面的时间轴和特效描述执行。

生成一个 10 秒、16:9 横屏、高端家庭动画电影质感的 3D 动画视频。一个连续镜头，同一个南极场景，从头到尾保持同一机位、同一地平线、同一前景冰面、同一中央蓝色冰山群、同一远处雪山轮廓、同一普通小动物区域、同一木制鱼桶位置。镜头可以非常轻微、平滑地向前推进，但不能切镜头，不能跳切，不能淡入淡出，不能换场景。

整体剧情必须是：平静南极 -> 天气异变 -> 风雪和云团向腹部中心漩涡聚合 -> 雪怪半成型抬升 -> 雪怪完整现身 -> 发出第一次暴风雪攻击。视频必须看起来像同一个场景里连续发生的事件，而不是几张图按顺序播放。

0-2 秒：平静南极。画面是宽广干净的南极冰原，淡蓝天空，前景有光滑冰面和少量反光，中景有稳定的蓝色冰山群，远处是雪山。普通小企鹅、小海豹等南极小动物在冰面上平静活动，木制鱼桶安静放在前景附近。此时没有雪怪，没有黑云，没有攻击，没有主角咕咕嘎嘎。

2-4 秒：危机开始。画面仍然保持完全同一个场景和同一构图。天空从一侧逐渐变暗，风开始变强，低矮雪雾贴着冰面卷动。细冰粉、霜雾微粒、半透明雪粉和很薄的冰蓝色光带开始从冰面、空气和云层边缘缓慢升起，像柔软发光的冰雾轨迹，而不是硬质冰晶。普通小动物开始抬头紧张，鱼桶可以轻微晃动但位置仍然清楚。远处中央冰山群后方只出现模糊的风暴云核，还不是怪物，没有眼睛，没有嘴，没有完整身体。

4-6 秒：雪怪开始由元素聚合生成。中央冰山群后方的风暴云核变强，所有细冰粉、霜雾、雪粉、薄雾光带、暗色云团和地面雪雾都被同一个腹部中心漩涡吸引。这个腹部漩涡是唯一生成核心，必须清楚看到它在旋转、吸入、聚合。雪怪不是从冰山后直接站起来，也不是整体龙卷风，而是由腹部中心漩涡从内向外逐层聚合。先形成一个不完整的深色雪云身体雏形，周围是流体般螺旋运动的冰雾和光带。此时雪怪仍未完成：没有完整头部，没有完整圆身体，没有完整手臂，没有手指，没有腿脚，没有攻击。蓝色眼睛可以在这个阶段后半段才隐约亮起，不能一开始就完整出现。

6-8 秒：半成型抬升。雪怪从中央冰山群后方逐渐抬高，身体变得大部分可读。深色雪云身体继续从腹部漩涡向外扩展，蓝色发光眼睛清楚点亮，云洞状大嘴逐渐打开，宽大的雪雾底座仍然和地面风雪连接。雪怪身上的少量冰质点缀只能附着在身体表面，不能变成空中漂浮的菱形冰晶或水晶道具。普通小动物开始逃跑，鱼桶在冰面上轻微滑动。雪怪相对于小动物和鱼桶很巨大，但必须明显小于大型冰山和远处雪山。

8-10 秒：完整现身和第一次攻击。雪怪完整现身，腹部中心漩涡短暂变亮，能量从漩涡向上流到云洞状大嘴。雪怪张嘴释放一束集中蓝白色暴风雪冲击，横向扫向旁边一座较小冰山。冲击命中点出现雪粉爆开、霜雾扩散和可读的碎冰块，但碎冰只发生在命中点附近，不要让全画面充满随机漂浮水晶。小动物继续逃跑，鱼桶可以滑动但不要消失。结尾保留同一个南极环境和同一个镜头，不要切到别的画面。

冰雪魔法特效要求：整体要干净、通透、柔和折射，像冰雾、雪粉和光在空气里流动。主要特效元素是极细粉尘状冰粒子、霜雾微粒、半透明雪粉、柔和冰蓝光带、流体螺旋轨迹和雪云体积变化。不要使用具体动画公司、电影、系列或 IP 名称。不要把“高级冰雪魔法”做成大块水晶、菱形冰晶、尖锐冰片或廉价闪光颗粒。

连续性要求：全片必须是同一场景、同一镜头中的连续变化。故事板只是参考阶段，不允许把故事板画面、分格、编号、字幕、边框或文字显示在视频里。不能硬切，不能淡入淡出，不能像播放不同图片。所有风、雪、云、雾、光带、腹部漩涡、眼睛点亮、嘴部打开、攻击发射都必须按时间轴流畅发生。

声音设计参考：前 2 秒是平静风声和小动物环境声；2-4 秒风声逐渐增强，低频云层轰鸣出现；4-6 秒腹部漩涡出现低频嗡鸣，细冰粉和霜雾被吸入时有轻微沙沙旋转声；6-8 秒雪怪成型时加入沉闷云状咆哮；8-10 秒攻击时加入蓝白冰束轰鸣、冻结噼啪声、冰面刮擦声、雪粉爆开声和远处小动物惊叫声。

Avoid: 多张关键帧剪辑感、幻灯片感、故事板分格出现在画面里、故事板白边、故事板编号、故事板字幕、文字、logo、水印、硬切、跳切、淡入淡出、换场景、机位改变、地平线改变、冰山布局改变、远山轮廓改变、前景冰面改变、鱼桶消失、主角咕咕嘎嘎提前出现、红围巾、蓝色发卡、完整雪怪太早出现、开头就有完整怪物、没有生成过程、雪怪只是从冰山后站起来、整体龙卷风、垂直龙卷风柱、攻击太早出现、怪物大于大型冰山、怪物大于远处雪山、山脉级怪物、怪兽电影尺度、肌肉手臂、拳头、手指、腿脚、王冠、胡子、尖牙、恐怖、血腥、写实灾难片、菱形冰晶、巨大漂浮冰晶、悬浮水晶、硬质水晶道具、尖锐冰片、冰刺碎片、廉价粒子闪光、随机闪亮碎片、全画面水晶碎片、竖图、错误画幅。
```
