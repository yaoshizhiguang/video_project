# 视频片段命名规则

## 预览片段

```text
ep001_seg01_preview_v001.mp4
ep001_seg01_preview_v002.mp4
```

## 正式片段

```text
ep001_seg01_final_v001.mp4
ep001_seg02_final_v001.mp4
```

## 选中片段

选中的片段复制到 `05_video_clips/selected/`，命名为：

```text
ep001_seg01_selected.mp4
ep001_seg02_selected.mp4
```

## 命名字段

- `ep001`：第 1 集。
- `seg01`：第 1 段。
- `preview`：低成本预览。
- `final`：正式生成候选。
- `selected`：最终选中。
- `v001`：版本号。
